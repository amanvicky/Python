# Python — Learning Curve

Scripts and notes from working through Python fundamentals — kept exactly as I learned, so the progression is honest.

## What's inside

- **Fundamentals** — `Variables.py`, `Dataypes.py`, `Operators.py`, `Conditions.py`, `Loops.py`, `Functions.py`, `Slicing.py`, `kwargs.py`, `Variable Lenght Arguments.py`
- **Control flow** — `Break And Continue.py`, `Continue Example.py`, `Loop2.py`
- **Stdlib & formats** — `Built-in Methods.py`, `Learn-JSON.json`
- **Small utilities** — `ostasks/` (file checks + OS tasks), `main.py`, `call-modern.py`
- **Fabric experiment** — `fabric/` (fabfile + a sample static site used as a deploy target)

## Run

```bash
python "Functions.py"     # or any file — most are self-contained demos
```
